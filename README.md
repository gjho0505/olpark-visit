# 올팍 갈까? — 올림픽공원 방문일 길잡이

한국체육산업개발(주) 개방 공공데이터(입출차·주차장 혼잡도·실시간 주차현황·공연/대관 오픈API)와 올림픽공원 누리집 공연 일정을 활용한 방문일 길잡이 시연판입니다.

- 화면1 달력: 오늘부터 2주 방문일 예상(KSPO DOME 공연일=빨강, 다른 공연장=노랑, 공연 없음=초록·여유 보장 아님), 2024년 7월 실측 달력
- 화면2 시간대: 날짜별 예상·경고와 같은 요일 실측 곡선, 실시간 주차대수(참고값), 입구별 비율
- 화면3 믿어도 돼요?: 기관 데이터 점검 결과 9건과 지난 기록으로 예상 규칙 검증

공연 일정은 `tools/update_events.py`가 GitHub Actions로 매일 06:00(KST) 자동 갱신합니다. 정적 웹(HTML·JS)이라 서버·운영비가 없습니다.
